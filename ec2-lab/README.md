# EC2 Linux Lab
## What I did
- Started an Amazon Linux 2023 EC2 instance.
- Connected securely using EC2 Instance Connect.
- Used the `ec2-user` Linux account.
- Checked the server user, folder, hostname, operating system, kernel, and free disk space.
- Created a practice folder and a text file.
- Created and ran a Linux system-information script.
- Stopped the EC2 instance after practice to control costs.

- pwd
- hostname
- cat /etc/os-release
- uname -r
- df -h /
