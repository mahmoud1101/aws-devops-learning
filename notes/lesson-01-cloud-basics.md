# Lesson 1: Cloud Computing Basics
AWS means Amazon Web Services.
Cloud computing means renting servers, storage, databases, and networking over the internet instead of buying and managing physical computers.
Important AWS services:
- EC2: virtual server
- S3: file storage
- IAM: users, permissions, and security
- VPC: private cloud network
- RDS: managed database
My goal: Learn AWS and DevOps to get an online job or freelance work.
