# Lesson 3: Linux Package Management

Package management is how Linux installs, updates, and removes software.

## Commands practised

- `sudo apt update` refreshes the list of available packages.
- `apt list --upgradable` shows packages with newer versions available.
- `sudo apt install -y tree` installs the tree command-line tool.
- `tree --version` checks that tree is installed.
- `tree -a -L 2 ~/permissions-lab` shows folders and files in a tree view.
